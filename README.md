#🔑 Генератор паролей на Python

Простой консольный инструмент для генерации безопасных паролей с гибкими настройками. Реализован с использованием ООП.

##✅ Возможности

- **Гибкая настройка:** выбор длины пароля и групп символов (строчные, заглавные, цифры, спецсимволы).
- **Валидация:** минимальная длина — 4 символа.
- **Умные подсказки:** предупреждение, если выбран только один тип символов (до 10 знаков); автоматическое включение строчных букв, если длина ≥ 11 и не выбраны другие опции.
- **Цикличность:** программа продолжает работу после каждой генерации.

##⚙️ Инструкции по сборке

- Клонируйте репозиторий: git clone https://github.com/<your_login>/pass_generator.git
- Установите зависимости: pip install -r requirements.txt (файл пуст, установка не потребуется).
- Запустите: python main.py.

##💡 Использование

- Введите желаемое количество символов (длина >= 4).
- Выберите категории символов: строчные, заглавные, цифры, спецсимволы (y — да, n — нет).
- Проверьте результат.
- Повторяйте генерацию, нажимая y. Для завершения введите n.
