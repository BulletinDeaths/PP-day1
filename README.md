## 📖 О проекте

`pass_generator` — простой консольный инструмент для генерации безопасных паролей с гибкими настройками. Реализован с использованием ООП.

---

## Возможности

| Функция | Описание |
|---|---|
| **Гибкая настройка** | Выбор длины пароля и групп символов |
| **Группы символов** | Строчные, заглавные, цифры, спецсимволы |
| **Валидация** | Минимальная длина — 4 символа |
| **Умные подсказки** | Предупреждение если не использовать ни одного типа символов (длина должна быть > 10 знаков) |
| **Цикличность** | Продолжение работы после каждой генерации, по желанию пользователя |

## ⚙️ Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/<your_login>/pass_generator.git
cd pass_generator
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

> 📌 Файл `requirements.txt` пуст — проект использует только стандартную библиотеку Python. Установка ничего не потребует.

### 3. Запустить

```bash
python main.py
```

## 💡 Использование

**Шаг 1** — Введите желаемую длину пароля `(≥ 4)`

```
Введите длину пароля: 16
```

**Шаг 2** — Выберите группы символов (`y` — да, `n` — нет)

```
Строчные буквы (a-z)?      [y/n]: y
Заглавные буквы (A-Z)?     [y/n]: y
Цифры (0-9)?               [y/n]: y
Спецсимволы (!@#$...)?     [y/n]: n
```

**Шаг 3** — Получите результат

```
✅ Ваш пароль: aB3kR7mQpL2xNv4w
```

**Шаг 4** — Повторите или завершите

```
Сгенерировать ещё один пароль? [y/n]: n
```

---

## 🧠 Логика валидации

```
Длина < 4            →   Ошибка: минимальная длина — 4 символа
Нет типов, длина ≥ 10 →  Возможность включеня только строчных букв
```
